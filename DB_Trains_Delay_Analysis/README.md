DB Train Delay Analysis
This project analyzes Deutsche Bahn (DB) train delays using data from the DB API marketplace. The dataset includes hourly snapshots of train arrivals, departures, and delays across 2000 stations in Germany over one week (08.07.2024 - 14.07.2024).

Key Features:

📍 Interactive Maps: Visualize delays across stations.
⏱️ Time-Series Analysis: Identify peak delay periods.
📊 Charts and Insights:
Highlight the busiest states and stations.
Visualize delay patterns across time and location.
